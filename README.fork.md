# vlc-android-fork

Форк [VLC for Android](https://code.videolan.org/videolan/vlc-android) с двумя добавлениями.
Лицензия — **GPLv2+**, как у оригинала. Полный изменённый исходный код лежит здесь же,
как того требует лицензия.

## Что добавлено

**Кнопка «Сообщить о проблеме»** — меню плеера (`⋮` во время воспроизведения),
работает и на Android TV с пульта. Пользователь выбирает, что не так, из списка;
приложение собирает диагностику и отправляет её на прокси, который заводит issue.

В отчёт входит: категория проблемы, модель устройства и версия Android,
разрешение/частота обновления/HDR экрана, список аудиовыходов, дорожки с кодеками
и частотой кадров, статистика воспроизведения (потерянные кадры, повреждённые блоки
демуксера, потерянные аудиобуферы) и последние 500 строк logcat.

Частота кадров файла и частота экрана собираются вместе намеренно: их несовпадение
(23.976 fps на экране 60 Гц) — самая частая причина рывков на Android TV.

**Обновление из релизов этого репозитория** — Настройки → Дополнительно →
«Проверить обновления». Тег релиза должен быть числом `versionCode`, например `3070111`.

## Безопасность

Токена GitHub в APK нет и быть не должно: приложение обращается к прокси
(Cloudflare Worker), токен хранится там.

Подлинность обновления обеспечивает Android — она откажется установить APK,
подписанный не тем ключом, что установленное приложение. Поэтому все сборки
подписываются одним постоянным keystore. Потеря ключа означает, что обновления
для уже установленных устройств станут невозможны.

## Сборка

Нативные исходники и NDK не нужны: `libvlc` и `medialibrary` берутся готовыми из Maven.

```
export JAVA_HOME=/opt/homebrew/opt/openjdk@17
export ANDROID_HOME=<путь к Android SDK>
gradle :application:app:assembleDebug
```

Требуется JDK 17, Android SDK (platform 36, build-tools 36.0.0), Gradle 9.3.1.

Сборка ставится рядом с официальным VLC: у неё пакет `org.videolan.vlc.debug`
и отдельное имя в лаунчере.

## Отношение к upstream

История VLC сохранена полностью, поэтому обновления из upstream подтягиваются обычным
`git rebase`. Правки сборочных файлов вынесены в отдельный коммит от правок с функциями.

```
git remote add upstream https://code.videolan.org/videolan/vlc-android.git
git fetch upstream && git rebase upstream/master
```
